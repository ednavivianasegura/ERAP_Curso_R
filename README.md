Curso: TRATAMIENTO DE CONJUNTO DE DATOS CON R


•	Manipulación de datos con dplyr y data.table:
-	Introducción a dplyr: selección, filtrado, agrupación, resumen y unión de datos.
-	Transformaciones y operaciones comunes (mutate, select, filter, arrange).
-	Uso de data.table para grandes conjuntos de datos.
-	Comparación entre dplyr y data.table.
-	Operaciones de mezcla y unión (join).
•	Manejo de datos desordenados y falta de Información:
-	Manejo de datos faltantes: NA, eliminación y sustitución.
-	Filtrado y ordenación de datos.
-	Transformaciones con datos desorganizados: spread, gather, pivot.
-	Limpieza de datos: detección de valores atípicos, errores tipográficos y duplicados.
-	Validación y verificación de la integridad de los datos.
•	Visualización de datos con ggplot2:
-	Introducción a la gramática de gráficos de ggplot2.
-	Creación de gráficos básicos: gráficos de dispersión, histogramas, diagramas de barras, boxplots.
-	Personalización de gráficos: títulos, leyendas, temas, escalas.
-	Visualización de múltiples variables.
-	Gráficos avanzados: facetas, gráficos de línea, gráficos con datos geoespaciales.
-	Exportación de gráficos.
•	Exploración de datos y estadística descriptiva:
-	Estadísticas descriptivas: media, mediana, varianza, percentiles.
-	Análisis de correlación y covarianza.
-	Tablas de frecuencia y análisis categórico.
-	Distribuciones de probabilidad básicas.
-	Análisis exploratorio de datos (EDA).
